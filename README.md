# Fichas Técnicas

App para restaurantes montarem fichas técnicas, calcularem custo de insumos, guardarem receitas e controlarem erros e perdas da cozinha.

- Cada pessoa cria a conta com e-mail e senha.
- Quem cria um restaurante vira dono e convida a equipe com um código.
- Acessos: Dono, Editor e Só visualiza.

Site estático (index.html) com dados no Supabase.
